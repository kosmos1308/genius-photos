# Фото для карточек Ozon (Genius)

## Что делаем
Массово загружаем фото на 5500+ типов товаров Ozon, чтобы категории были закрыты карточками-заглушками для договора с Си-Трейд.

## Что нужно от поставщика

**Файл `нужны-фото.csv`** (в этой же папке) содержит все типы Ozon, к которым нужно фото. Колонки:
- `type_id` — уникальный ID типа Ozon
- `description_category_id` — ID категории Ozon
- `путь` — иерархия категорий («Электроника / Наушники / TWS Earbuds»)
- `тип товара` — короткое название типа
- `статус` — «не создано» / «фото отклонено» / «другая ошибка»
- `ошибки` — техническая расшифровка

**Всего 5532 типа.** Достаточно ОДНОГО фото на каждый `type_id` (в идеале — на весь товар без фона, 800×800 или больше).

## Как класть фото

**Вариант 1: по type_id (лучший)**
- Формат: `photos/<type_id>.jpg` (или `.png`, `.webp`)
- Пример: `photos/504866264.jpg` (для TWS Earbuds)
- Работает автоматически — скрипт применит без ручного маппинга.

**Вариант 2: по группам категорий**
- Формат: `photos-by-category/<category_slug>/<name>.jpg`
- Скрипт разберёт по имени типа (fuzzy match).

**Вариант 3: одна папка с фото + Excel маппинг**
- Все файлы в `photos/` с любыми именами.
- Файл `mapping.xlsx` с колонками `filename` | `type_id` (или `type_name`).

## Требования к фото (Ozon)

- **Формат**: JPG, PNG или WebP
- **Размер**: минимум 200×200 пикселей (лучше 800×800)
- **Фон**: белый (Ozon требует)
- **Вес**: до 10 МБ
- **Уникальность**: каждое фото должно быть уникальным для Ozon (не украдено с других карточек)

## Что делает автоматика

После помещения фото в `photos/`:
1. Скрипт заливает их на GitHub Pages (публичный HTTPS)
2. По `type_id` формирует URL `https://<user>.github.io/genius-photos/photos/<tid>.jpg`
3. Обновляет карточки Ozon через API — переимпорт с новым фото
4. Модерация Ozon проверяет и переводит карточки в «Готов к продаже»

## Ожидаемый результат

При покрытии 5500 фото: **9200+ карточек «Готов к продаже» из 9229 типов Ozon** (~100% покрытие).
